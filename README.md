# גולני: שומר העץ

משחק דפדפן תלת־ממדי בגוף ראשון לנייד. הגן על עץ הזית מ־10 גלי זומבים.
`index.html` הוא המשחק כולו (קובץ אחד). הקוד נמצא בתיקייה `source` (Three.js, בנייה עם `node build.mjs` אחרי `npm i three esbuild`).

Golani: Guardian of the Tree. A mobile first-person browser zombie-wave defence game (Three.js, WebXR AR with camera fallback).
